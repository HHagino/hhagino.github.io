# FCIG Model XX — Adiabatic elliptic family / Kaluza--Klein response

**Status:** COMPLETE in the restricted fixed-volume scalar model, with the finite tower response defined by Epstein/zeta analytic subtraction. No Einstein equation or horizon law is inferred.

## 1. Goal

Model XIX established the exact constant-modulus identity

\[
-\partial\bar\partial\log\det{}'\Delta_\tau=F_{\lambda_H}.
\]

Model XX asks a different, typed question. Let

\[
\tau=\tau(x)=u(x)+iY(x)
\]

vary over a four-dimensional base. What genuine spacetime two-derivative response is generated by the intrinsic elliptic Kaluza--Klein tower?

The first pass is deliberately restrictive: locally trivial \(T^2\), fixed fiber area, no KK vectors, one real minimally coupled six-dimensional scalar. This restriction makes the local operator decomposition exact and keeps every additional datum visible.

---

## 2. Fixed local family geometry

Let \((M_4,g_{\mu\nu})\) be Euclidean and set locally

\[
X_6=M_4\times T^2.
\]

Use

\[
\boxed{
 ds_6^2
 =g_{\mu\nu}(x)dx^\mu dx^\nu
 +L^2G_{ab}(\tau(x))dy^a dy^b,
}
\]

with \(y^a\sim y^a+1\) and

\[
\boxed{
G(\tau)=\frac1Y
\begin{pmatrix}
1&u\\
u&u^2+Y^2
\end{pmatrix},
\qquad \det G=1.
}
\]

Thus

\[
\sqrt{g_6}=L^2\sqrt{g_4}.
\]

The volume modulus is frozen. The standard toroidal/coset background is reviewed in Maharana--Schwarz [MaharanaSchwarz1993].

## 3. Exact scalar Laplacian: no local Berry mixing in this restricted model

For a minimally coupled scalar,

\[
\Delta_6
=-\frac1{\sqrt{g_6}}\partial_M
\left(\sqrt{g_6}\,g_6^{MN}\partial_N\right).
\]

Block diagonality, fiber-coordinate independence and \(\det G=1\) give exactly

\[
\boxed{
\Delta_6
=\Delta_4
-\frac1{L^2}G^{ab}(\tau(x))\partial_a\partial_b.
}
\]

Use the coordinate Fourier basis

\[
\chi_{m,n}(y)=e^{2\pi i(my^1+ny^2)},
\qquad (m,n)\in\mathbb Z^2.
\]

It is independent of \(x\) and \(\tau(x)\) in this local trivialization. Hence

\[
\Delta_6\Psi
=\sum_{m,n}
\left[\Delta_4+M_{m,n}^2(\tau(x))\right]\phi_{m,n}\chi_{m,n},
\]

with

\[
\boxed{
M_{m,n}^2(\tau)
=\frac{4\pi^2}{L^2Y}|m\tau-n|^2.
}
\]

> **Result XX.1 (Derived here).** In the block-diagonal, fixed-volume, locally trivial scalar model there is no local Berry/off-diagonal mode mixing. All local modulus dependence enters through the intrinsic KK masses.

Nontrivial torus bundles, KK gauge fields, other representations and global modular patching remain separate extensions.

## 4. Total-space curvature forces the Poincare tensor shape

For the same metric,

\[
\boxed{
R_6
=R_4
-\frac14g^{\mu\nu}
\operatorname{Tr}
\left(G^{-1}\partial_\mu G\,G^{-1}\partial_\nu G\right).
}
\]

This is the standard toroidal shape-modulus structure [MaharanaSchwarz1993]. For the elliptic matrix,

\[
\boxed{
\operatorname{Tr}(G^{-1}dG\,G^{-1}dG)
=2\frac{du^2+dY^2}{Y^2}.
}
\]

Therefore

\[
\boxed{
R_6
=R_4-rac1{2Y^2}\partial_\mu\tau\partial^\mu\bar\tau.
}
\]

> **Result XX.2 (Derived here / standard reduction specialized here).** The Poincare tensor shape of the spacetime two-derivative modulus invariant is intrinsic to the total-space torus geometry; it is not obtained by fitting arbitrary spectral functions.

## 5. Local UV sector

For one real scalar,

\[
W_{1\text{-loop}}
=\frac12\log\det\Delta_6
=-\frac12\int_\epsilon^\infty\frac{dt}{t}\operatorname{Tr}(e^{-t\Delta_6}).
\]

The standard six-dimensional heat kernel contains [Vassilevich2003]

\[
\operatorname{Tr}(e^{-t\Delta_6})
\sim(4\pi t)^{-3}\int\sqrt{g_6}\left(1+t\frac{R_6}{6}+\cdots\right).
\]

With the sharp proper-time convention \(\epsilon=\Lambda^{-2}\),

\[
\boxed{
W_{\rm div}^{(R)}
=-\frac{\Lambda^4}{24(4\pi)^3}\int_{X_6}\sqrt{g_6}\,R_6.
}
\]

Thus

\[
\boxed{
W_{\rm div}^{(\tau)}
=\frac{\Lambda^4L^2}{48(4\pi)^3}
\int_{M_4}\sqrt{g_4}\,
\frac{\partial_\mu\tau\partial^\mu\bar\tau}{Y^2}.
}
\]

The tensor shape is Poincare, but this coefficient renormalizes the allowed local six-dimensional Einstein--Hilbert coupling. Power-divergent normalizations are regulator/counterterm sensitive. Von Gersdorff explicitly separates UV-sensitive local and UV-insensitive nonlocal sectors in toroidal one-loop effective actions [vonGersdorff2008].

> **Result XX.3.** The leading local spacetime Poincare kinetic normalization is not a parameter-free FCIG prediction.

## 6. KK bubble and the divergent tensor sum

Define

\[
\boxed{
Q_{m,n}(\tau)=\frac{|m\tau-n|^2}{Y},
\qquad
M_{m,n}^2=\alpha Q_{m,n},
\qquad
\alpha=\frac{4\pi^2}{L^2}.
}
\]

Model XVIII fixed the one-real-scalar constant-background 1PI two-point convention

\[
G^{(m,n)}_{AB}
=\frac1{192\pi^2}
\frac{\partial_AM_{m,n}^2\partial_BM_{m,n}^2}{M_{m,n}^2}.
\]

Hence the formal nonzero-tower tensor is

\[
G^{\rm tower}_{AB}
=\frac{\alpha}{192\pi^2}
\sum_{(m,n)\ne(0,0)}
\frac{\partial_AQ_{m,n}\partial_BQ_{m,n}}{Q_{m,n}}.
\]

The sum is power divergent, consistently with the six-dimensional heat-kernel result. It must not be interpreted before a local subtraction prescription is fixed.

## 7. Hyperbolic identities for one lattice quadratic form

Let

\[
g_{\rm hyp}=\frac{du^2+dY^2}{Y^2}
\]

with Levi--Civita connection \(\nabla\). Direct calculation gives, for every nonzero lattice vector,

\[
\boxed{
\nabla_A\nabla_BQ_{m,n}=Q_{m,n}\,g^{\rm hyp}_{AB},
\qquad
|dQ_{m,n}|_{g_{\rm hyp}}^2=Q_{m,n}^2.
}
\]

These identities are the key to separating the trace/local sector from the finite modular sector.

## 8. Epstein analytic continuation of the tower tensor

Introduce the determinant-one Epstein zeta family

\[
\boxed{
Z_\tau(s)=\sum{}'Q_{m,n}(\tau)^{-s},
\qquad \Re s>1,
}
\]

and the tensor family

\[
\mathcal T_{AB}(s)
=\sum{}'Q^{-s-2}\partial_AQ\partial_BQ.
\]

The desired formal tower tensor corresponds to \(s=-1\). Using the Hessian identity above,

\[
\boxed{
\nabla_A\nabla_BZ_\tau(s)
=-sZ_\tau(s)g^{\rm hyp}_{AB}
+s(s+1)\mathcal T_{AB}(s).
}
\]

The Epstein zeta function has meromorphic continuation and the standard functional equation [Terras2013; Terras1980]. Because the determinant-one two-dimensional quadratic form is self-dual up to an integral lattice rotation,

\[
\boxed{
\pi^{-s}\Gamma(s)Z_\tau(s)
=\pi^{s-1}\Gamma(1-s)Z_\tau(1-s).
}
\]

Expanding at \(s=-1\) yields

\[
\boxed{
Z_\tau(-1)=0,
\qquad
Z_\tau'(-1)=-\frac1{\pi^3}Z_\tau(2).
}
\]

Therefore the apparent singularity of \(\mathcal T_{AB}(s)\) at \(s=-1\) is removable after analytic/local subtraction, and

\[
\boxed{
\mathcal T^{\rm fin}_{AB}
:=\operatorname*{FP}_{s=-1}\mathcal T_{AB}(s)
=\frac1{\pi^3}
\left(
\nabla_A\nabla_BZ_\tau(2)
-Z_\tau(2)g^{\rm hyp}_{AB}
\right).
}
\]

Here `FP` denotes the analytic finite part in this Epstein/zeta subtraction convention.

## 9. Exact trace-free theorem

The same lattice sum is a real-analytic Eisenstein/Epstein eigenfunction:

\[
\Delta_{\rm hyp}Z_\tau(s)=s(s-1)Z_\tau(s)
\]

in the sign convention used here [Terras2013]. At \(s=2\),

\[
\Delta_{\rm hyp}Z_\tau(2)=2Z_\tau(2).
\]

Hence

\[
\boxed{
g_{\rm hyp}^{AB}\mathcal T^{\rm fin}_{AB}=0.
}
\]

> **Result XX.4 (Derived here).** In the Epstein/zeta subtraction of the restricted six-dimensional scalar model, the finite nonlocal two-derivative tower response is exactly hyperbolically trace-free. The entire Poincare-trace sector belongs to the local/counterterm ambiguity.

This sharply answers the question left open in the first version of Model XX: the finite threshold is **not** another constant multiple of \(g_{\rm hyp}\).

Within a six-dimensional local-covariant renormalization of the pure metric two-derivative sector, the available counterterm \(\int\sqrt{g_6}R_6\) shifts the Poincare trace sector. A purely four-dimensional EFT with arbitrary additional local modulus counterterms would have more scheme freedom; the present statement keeps the fixed six-dimensional parent model.

## 10. Holomorphic weight-four form of the finite threshold

Define the absolutely convergent weight-four lattice Eisenstein series

\[
\boxed{
\mathcal G_4(\tau)
:=\sum_{(m,n)\ne(0,0)}\frac1{(m\tau-n)^4}.
}
\]

Holomorphic Eisenstein series and their modular weights are standard [Apostol1990]. Directly rewriting the trace-free Hessian gives

\[
\boxed{
\mathcal T^{\rm fin}
=-\frac{3}{\pi^3}
\operatorname{Re}\!\left[\mathcal G_4(\tau)(d\tau)^2\right].
}
\]

Since

\[
\mathcal G_4(\gamma\tau)=(c\tau+d)^4\mathcal G_4(\tau),
\qquad
d(\gamma\tau)=\frac{d\tau}{(c\tau+d)^2},
\]

the real quadratic tensor above is globally modular invariant.

Multiplying by the one-loop bubble coefficient gives the finite spacetime response

\[
\boxed{
G^{\rm fin}_{AB}d\Phi^Ad\Phi^B
=-\frac1{16\pi^3L^2}
\operatorname{Re}\!\left[\mathcal G_4(\tau)(d\tau)^2\right].
}
\]

Equivalently,

\[
\boxed{
W^{\rm fin}_{(2)}
=-\frac1{32\pi^3L^2}
\int_{M_4}\sqrt{g_4}\,
\operatorname{Re}\!\left[
\mathcal G_4(\tau)
\partial_\mu\tau\partial^\mu\tau
\right]
}
\]

in the Model-XVIII 1PI normalization.

> **Result XX.5 (Derived here).** The finite modular threshold is a weight-four, trace-free automorphic tensor. It is not a positive-definite sigma metric by itself.

A nonzero trace-free symmetric tensor in two real dimensions has opposite-sign eigenvalues. Therefore the physical positive kinetic tensor must include the independently renormalized local Poincare term,

\[
G^{\rm ren}_{AB}
=Z_R\,g^{\rm hyp}_{AB}+G^{\rm fin}_{AB}+\cdots.
\]

The determinant fixes the modular threshold above, but it does not fix the renormalized positive coefficient \(Z_R\).

## 11. Relation to Model XIX: exact distinction, not identification

Model XIX found

\[
\boxed{

=F_{\lambda_H}
\propto g_{\rm hyp}
}
\]

as a finite **moduli-space \((1,1)\) Chern-curvature identity**.

Model XX instead finds, after local spacetime renormalization,

\[
\boxed{
G^{\rm fin}_{(2)}
\propto
\operatorname{Re}[\mathcal G_4(\tau)(d\tau)^2],
\qquad
\operatorname{tr}_{g_{\rm hyp}}G^{\rm fin}_{(2)}=0.
}
\]

Thus the two spectral responses are genuinely different tensor projections of the same elliptic family data:

\[
\boxed{
\text{constant-modulus determinant Chern curvature}
\neq
\text{spacetime adiabatic finite threshold}.
}
\]

This resolves the type gap rather than hiding it.

## 12. Cusp / validity boundary

For \(Y\to\infty\),

\[
M_{0,n}^2=\frac{4\pi^2n^2}{L^2Y}\to0.
\]

The nonzero tower therefore ceases to be uniformly heavy. Although the modular tensor formula has an analytic continuation, interpreting it as a local low-energy derivative expansion near the cusp is not justified.

> **Result XX.6.** The cusp remains an explicit EFT validity boundary.
